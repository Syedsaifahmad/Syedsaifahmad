### 2. ESP32 FreeRTOS Multi-Sensor Data Logger

**ESP32 | Embedded C | FreeRTOS | I2C | SPI | UART**

A multitasking ESP32-based data logging system using FreeRTOS to acquire, process and transmit sensor data.
